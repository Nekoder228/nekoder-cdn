Privacy Policy — Nekoder Uploader

Last updated: 8 November 2026

Nekoder Uploader is a private tool used only by the owner of the TikTok account @dnevnik_nekodera.

Data we access

With the owner's authorization, the tool receives a TikTok access token with the user.info.basic and video.upload scopes, used only to send the owner's own images to his TikTok inbox.

Storage

Access tokens are stored as encrypted secrets and are never shared. Images are hosted only temporarily so TikTok can fetch them, then deleted. No data from other TikTok users is collected, stored or processed.

Sharing

No data is sold or shared with third parties.

Deletion

The owner can revoke access at any time in TikTok settings (Security → Manage app permissions).
